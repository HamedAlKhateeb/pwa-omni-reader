# تحقق الصورة المصغرة وتنظيم الهاتف

أضيف مقال اختبار محلي في بيئة التطوير بصورة مصغرة عامة فقط، ثم أعيد فتح المكتبة. ظهرت الصورة في بطاقة المقال مع اسم المصدر والعنوان والوصف وزمن القراءة والتقدم. لا يرفع هذا الاختبار أي بيانات إلى Supabase أو إلى GitHub Pages.

يستخرج الخادم الصورة بالترتيب من `og:image` ثم `twitter:image` ثم صورة مناسبة في جسم المقال، ويحوّل العناوين النسبية إلى روابط كاملة قبل حفظها محليًا.

على الشاشات الضيقة تصبح بطاقة المقال ذات الصورة صفًا مضغوطًا: الصورة في عمود ثابت، والعنوان والملخص في العمود الآخر، ثم بيانات التقدم في صف كامل. يبقى البحث، الفرز، الحفظ، والقائمة قابلة للوصول باللمس دون تجاوز أفقي.

أعيد التحقق من GitHub Pages بعد النشر في Chromium مستقل وبملف مستخدم نظيف. أضيفت بطاقة اختبار محلية داخل المتصفح فقط، وظهرت الصورة المصغرة بوضوح في بطاقة المكتبة المنشورة مع المصدر والعنوان وملخص المقال. لا تدخل بطاقة الاختبار هذه في بيانات أي مستخدم أو في المستودع.
