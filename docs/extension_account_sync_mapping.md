# خريطة نقل الحسابات والمزامنة من الإضافة الأصلية

## طريقة الحسابات الأصلية

تستخدم الإضافة حسابات البريد الإلكتروني وكلمات المرور في مشروع Supabase نفسه. تدعم إنشاء الحساب، تأكيد البريد، تسجيل الدخول، تجديد جلسة الوصول، استعادة كلمة المرور، وتسجيل الخروج. ستستخدم واجهة الويب عنوان مشروع Supabase ومفتاح `anon`/publishable فقط عبر متغيرات بيئة؛ ولن تحتوي على Service Role أو مفتاح خاص.

## آلية المزامنة الأصلية

تحفظ الإضافة كل فئة بيانات في سجل مستقل داخل جدول `user_data` باستخدام زوج `user_id` و`data_key`. يعتمد النقل على pull ثم merge ثم push، مع دمج العناصر المعتمدة على المعرفات، وحفظ الحذف المحلي، وحل تعارضات القيم المفردة باختيار نسخة الجهاز أو الخادم. تُزال المقالات كاملة النص والصور المضمنة من حمولة السحابة لتقليل الحجم؛ يحتفظ الجهاز بنسخة القراءة المحلية متى كانت متاحة.

## الإعدادات المنقولة إلى الويب

| فئة | المفتاح الأصلي | تطبيق الويب |
|---|---|---|
| المظهر | `reader_theme`, `library_bg_color` | سمة القارئ وخلفية المكتبة |
| النص | `reader_font_size`, `reader_font`, `reader_line_height`, `reader_word_spacing`, `reader_align`, `reader_width` | حجم الخط وعائلته وتباعد السطور والكلمات والمحاذاة والعرض |
| اتجاه ومحتوى | `reader_rtl`, `reader_show_photos` | اتجاه القراءة والصور |
| المكتبة | `reader_bookmarks`, `reader_folders`, `reader_notes`, `reader_highlights`, `reader_positions` | المقالات والمجلدات والملاحظات والتمييز والتقدم |
| تفضيلات المواقع | `reader_important_sites`, `reader_auto_open_sites`, `reader_auto_open_enabled` | تُزامن كبيانات تفضيل؛ الفتح التلقائي خاص بالإضافة ولا يُنفذ داخل PWA |
| قواعد المواقع | `reader_custom_rules` | تُحفظ للمزامنة مع الإضافة ولا تُنفذ داخل PWA، لأن تشغيل JavaScript مخصص من إعدادات المستخدم داخل موقع عام غير مناسب أمنيًا |

النتيجة: تسجيل الدخول نفسه يربط التطبيق والإضافة بالحساب نفسه، والمزامنة ستكون فعلية بعد تشغيل سياسات RLS الموجودة في المشروع والتحقق منها.
